ALPINE ASCENTS — NEON VIP PRO EDITION
=====================================

A premium, responsive multi-page mountain-adventure website with a dark neon-cyan / electric-blue / violet theme.

Pages included:
- index.html — Home
- about.html — Mountaineering guide
- packages.html — Adventure packages + interactive group budget estimator
- safety.html — Safety guide
- records.html — Mountain records
- clubs.html — Locations and map
- gallery.html — Photo gallery with click-to-enlarge lightbox
- news.html — Updates
- booking.html — Demo booking enquiry form
- style.css — Complete responsive theme, neon effects and animations
- script.js — Mobile menu, live date/time ticker, scroll progress, back-to-top, neon boost toggle, reveal effects, gallery lightbox, booking demo validation and package budget calculator

How to run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser or use the Live Server extension.

Features:
- Responsive mobile navigation
- Neon hover and glow effects
- Optional Neon Boost button (floating ✦)
- Scroll reading-progress bar and Back-to-top button
- Smooth reveal animations (respects reduced-motion settings)
- Gallery image lightbox
- Interactive PKR group budget calculator on Packages page
- Booking form front-end validation with demo-only confirmation
- Live date/time ticker and dynamic footer year

Important:
- Photos, Google Fonts and map embeds may require an internet connection.
- Prices (PKR 25,000 / 65,000 / 185,000) are illustrative demo prices, not confirmed commercial offers.
- The booking form does not transmit or store booking details; this is a frontend student project.
